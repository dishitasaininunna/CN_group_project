# D1 - SDN Socket Programming: Packet Loss Detection and Recovery

## Project Overview

This stage implements a UDP-based client-server application for packet transmission and packet-loss handling, integrated with a Software Defined Networking (SDN) environment.

## Files

- controller.py - SDN controller implementation.
- topology.py - Mininet network topology.
- udp_measured_server.py - UDP server implementation.
- udp_measured_client.py - UDP client implementation.

## Environment

- Ubuntu
- Python 3
- Mininet
- Open vSwitch
- OS-Ken SDN controller

## Purpose

The implementation provides the foundation for UDP communication and SDN-based network management. The D2 version extends the project with additional functionality and performance evaluation.
